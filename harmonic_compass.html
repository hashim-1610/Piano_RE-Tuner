Project notes

What this project does

Ben Johnston’s Sonata for Microtonal Piano asks the pianist to retune all 88 strings to specific just-intonation pitches instead of the usual equal temperament. In the original, this is done physically with a Scalatron tuner.

Harmonic Compass reproduces that tuning digitally: you play a digital piano, and the sound you hear is generated at Johnston’s frequencies.

How it works

  1. Play a key on the digital piano.
  2. The piano sends a MIDI note message over USB.
  3. The browser reads it through the Web MIDI API.
  4. The app looks up that key’s target frequency in the Johnston table.
  5. The Web Audio API plays a tone at exactly that frequency.
No pitch-bend is used. Each note is synthesised at its own exact frequency, so chords with several different offsets sound correctly at once.

Reading the display

  • Cents measure pitch differences: 100 cents = 1 semitone.
  • Offset is how far Johnston’s pitch is from standard tuning (A4 = 440 Hz). A positive value is sharper, a negative value is flatter.
  • Key 37 (A3, 220 Hz) is the anchor: offset 0.
  • The extremes are far from standard: key 1 is about −56¢ and key 88 about +175¢. That is expected for this piece.
  • Use the Tuning switch to compare Johnston against standard tuning.

Setup tips

  • Use Chrome or Edge. Firefox and Safari do not support Web MIDI.
  • Connect the piano by USB before opening the page, and allow the MIDI permission.
  • Switch Local Control OFF in the piano’s settings, otherwise you also hear its own untuned sound.
  • The sustain pedal is supported. Velocity controls loudness.
  • Use headphones or the laptop speakers; the piano’s speakers are not used.

Data & editing the tuning

The 88 frequencies come from the “Retuning the Piano” table in the score (the Scalatron switch settings are not needed here). They are stored in tuning.yaml.

To correct a value, edit tuning.yaml and run python generate_js_table.py; this page is rebuilt from it automatically.

Limitations

  • The sound is a simple synthesised tone, not a sampled piano. Pitch accuracy is the goal here.
  • Small latency (a few milliseconds) between key press and sound.
  • Notes outside the 88-key range are ignored.
  • This simulates the retuned piano electronically. It does not change the strings of an acoustic piano.
